# mkcloud IX：接入条件、四条线路与真实价格一次讲清，跨境电商后台和 API 出海这样选

## 先说清楚：mkcloud IX 不是交换中心成员资格

很多人看到 IX 三个字母，第一反应是「是不是要我有自己的 ASN、去交换中心做 Peer」。不是。Mkcloud 官方知识库的表述很明确：Mkcloud IX 是通过支持云厂网络接入的出海 VPS，零售用户不需要自己的 ASN，也「不能据此推断能与所有成员直接对等」。

它的实际工作方式是这样的：每台 IX VPS 分配 **1 个独立入口 IP 和 1 个独立出口 IP**。你用云服务器连接入口 IP 登录 VPS，在 VPS 里运行业务程序，程序向境外目标发起的访问会自动从出口 IP 发出去。入口走的是云厂内网/交换网络，不暴露在公网上；出口是香港、日本或美国的 BGP 网络。

这个结构决定了它的两个特点：

- **入口不是公网地址**。只有阿里云、腾讯云这类被允许的云厂网络能连进来，三大运营商的普通家宽反而不行。第三方测评（catcat.blog 2026 年 1 月的实测文章）把这点列为 IX 的核心优势：入口几乎无法被公网扫描，大规模 DDoS 的攻击成本也被抬高，因为攻击者得先摸到你的前置云机。
- **出口只出不进**。出口 IP 不接受外部连入，官方明确列了不能干的事：公开建站、支付回调、邮件接收、游戏服务端。它适合的是「你主动去访问境外服务」的场景——店铺后台、已授权的 API、文件上传、客户端测试。

## 一台 IX VPS 怎么工作：入口、出口和云厂前置

买 IX 之前要理解一件事：你不是买一台「直连专线的机器」，而是买「一条从云厂网络通往境外的通道」+ 一台 VPS。所以完整的连接链路是三层：

1. 你的电脑或办公室网络，连到一台云厂服务器（前置机）；
2. 前置机通过云厂内网连到 Mkcloud IX 的入口；
3. VPS 里的业务程序从境外出口向外访问。

官方给出的接入范围是：深圳入口支持阿里云、腾讯云、百度云国内全网，以及火山云、华为云华南；上海入口支持阿里云、腾讯云、百度云国内全网，以及火山云、华为云、UCloud 华东。具体以购物车说明为准。IX 不限绑定省份，这是它和广港、沪港这类直连产品最大的区别——直连款会把入口锁死在一个省份。

还有一条容易忽略：官方明确说不默认支持用普通 BGP 主机代替云前置。也就是说，你在 IDC 买的一台普通国内 VPS 不能拿来当前置，得是上述云厂的机器。

## 前置云机怎么准备，成本要算多少

这是 IX 方案最容易低估的部分。套餐价格只是总成本的一部分，前置云机的机器费和流量费要另算。

前面提到的 catcat.blog 实测作者用的方案是火山引擎 ECS：机器约 550 元/年，共享流量包约 437 元/TB/年（作者自费购买的价格）。而沪日 IX 1TB 档本身每月就有 1TB 流量额度，前置机如果也走 1TB 流量，一个月的流量开销大概在 36 元左右（按上述流量包价格估算），再加机器费分摊。这个结构带来的直接结论是：**如果你手上没有现成的云厂资源，IX 的「便宜」要打个折扣再评估**。

反过来，如果你的业务本来就跑在阿里云或腾讯云上，前置机是现成的，IX 的性价比就明显了。同样以沪日方向为例：官方知识库给出的沪日 IPLC 直连共享入门是月付 288 元（1 核/2GB/20GB/200Mbps/1024GB 月流量），而走 IX 入口的沪日 1TB 档是 166 元/月、配置还高一级。差价来源于入口：IX 入口走云厂网络，比电信入口的带宽成本低，这也是第三方测评里说的「IX 售价比其他入口便宜且流量更多」的原因。

选前置机还有一个坑：阿里云、腾讯云的轻量实例标称 200M 带宽，但轻量实例的带宽不保证，已有被实际限速到 20M 甚至 1M 的案例；火山云延迟表现好但没有轻量形态，按量流量约 0.8 元/GB，长期跑成本不低。前置机的稳定性直接决定 IX 体验，这一层要自己兜底。

## 买之前必须知道的几条限制

这些全部来自官方知识库原文，比任何评测都重要：

- **出口不收流量**。不能承载公开网站、买家页面、支付回调、邮件接收、游戏服务端。想建站的用户需要的是能公网连入的服务器，不是这款产品。
- **默认无 SLA**。官方不承诺无中断或固定故障恢复时长，金融滑点改善之类的承诺也不会有。需要 SLA 可以咨询付费定制。
- **退款门槛高**。仅质量问题支持退款，需要在工单里提交测试截图和具体问题，由 Mkcloud 审核判断；开通后不支持更换到其他地域。换句话说，方向选错了没有后悔药，下单前把目标地区确认清楚。
- **IP 不保证干净度**。出口是服务器 IP，不保证原生、住宅、流媒体解锁或历史完全干净，独享 IP 也不保证平台账号不被限制。跨境店铺运营者如果对 IP 历史敏感，下单前先想清楚这一点。
- **合规责任在用户**。全线产品需实名认证，官方对正规用途的定义是不进行回国等违法行为。数据传输的许可和跨境合规要求需要自己核验。

## 常见问题

**mkcloud IX 需要我有自己的 ASN 或者加入交换中心吗？**
不需要。它是面向零售用户的 VPS 产品，交换中心成员接入是另一类服务，Mkcloud 官方明确说不能把两者混为一谈。

**我在深圳，是不是选深港 IX 就一定最快？**
不一定。官方特别提醒：不能仅因人在深圳就认定适合 IX。你要先确认自己的前置云机在网络支持范围内，再看业务目标是香港还是别的地方。人在深圳但目标服务在日本的场景，沪日 IX 反而更对口。

**共享款带宽 200Mbps 是指持续速度吗？**
不是。共享带宽是峰值，不保证持续跑满；持续传输需求应该看独享款或者更大的流量档。官方还提醒，200Mbps 共享和 5Mbps 独享对应不同计费资源，不能说 5Mbps 独享一定比 200Mbps 共享快。

**一台机器能几个人用？**
官方没有按账号数限制，产品层面不限制 TCP、UDP、端口和并发数量，禁止违法用途。账号数量也不是判断要不要买独享的依据。

**沪日 IPLC 和沪日 IX 怎么选？**
官方的选型建议是：先看你的接入条件——直连款绑定一个省份（电信入口），IX 需要支持的云厂网络；再比较费用。已有云厂资源、目标只是让 VPS 向外访问的，IX 通常更便宜；需要电信入口直连的，选 IPLC。
